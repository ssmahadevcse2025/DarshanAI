# Team Collaboration & Auto-Sync Rule

Whenever starting any conversation, session, or implementing changes in this workspace:
1. Check `git status` and pull the latest changes from `origin/main` using `git pull --autostash origin main` or `./pull_latest.bat`.
2. Proactively confirm with the developer: *"Checking and pulling latest updates from remote repository to keep in sync with teammates."*
3. Always push completed features and fixes to `origin/main` so your team collaborators receive them immediately.
